TAREFAS E ANOTACOES - APLICATIVO
================================

1) BANCO DE DADOS (PostgreSQL)
   Crie um banco vazio chamado tarefas_anotacoes e execute, nesta ordem:
     banco/criacaoTabelas.sql
     banco/insercaoDados.sql

2) BACKEND (terminal 1)
   cd backend
   cp .env.example .env        (ajuste usuario/senha do banco e gere o JWT_SECRET)
   node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
   npm install
   npm run dev                 (API em http://localhost:3000)

3) APLICATIVO (terminal 2)
   cd mobile
   npm install
   npm run web                 (abre no navegador em http://localhost:8081)

   Dica: use as ferramentas do desenvolvedor do navegador (F12) para
   simular a tela de um celular e acompanhar as requisicoes na aba Rede.
